🎯 Attack Simulation Sandbox

Test the robustness of HMAC-SHA256 verification and TTL-bounded scopes against simulated malicious agent behaviors.

Scope Violation Attack

Shopping Agent attempts to call 'checkout' tool, which was omitted from its cryptographic scope token. System should block it.

Token Expiry Attack

Shopping Agent waits for its short (10s) cryptographic scope TTL to expire, then attempts to make a tool call. System should reject.

Signature Forgery Attack

A compromised sub-agent modifies its cryptographic token data payload directly, forging the HMAC. System signature verification should fail.
