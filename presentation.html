The Problem Space

AI Agents Act. Nobody Authorized Them.

"When something goes wrong, nobody can answer the most basic question: who authorized that action, and did the agent that ran it actually have the right to? The delegation chain is invisible."
🧩

What is the problem?

AI agents delegate sub-tasks to other agents with no cryptographic proof of authority. Sub-agents inherit implicit trust and can act far beyond their intended scope.

👥

Who is affected?

Enterprises deploying multi-agent systems, end-users whose personal data and finances are handled, and developers who can't audit what their systems actually did.

⚡

Existing solutions?

Role-based access control (RBAC), sandboxing, manual logs. These are static, don't track delegation chains, and are trivially bypassed by an agent with broad context.

🚨

Key gaps / limitations

No receipts. No scope expiry. No proof-of-authorization. No way to trace a tool call back to the original user intent. Nothing stops a sub-agent from checking out your cart.

Our Solution

Personal Assistant Swarm + ArmorIQ Governance

❌ Without AuthorChain Shopping agent calls checkout() with your real card. No one knows who authorized it, when, or why. There's no log. The cart empties.
✅ With AuthorChain Shopping agent attempts checkout() → ArmorIQ SDK blocks it. Scoped token only allows search + add_to_cart. Violation is logged immutably. You stay safe.

Innovation Highlights

Key Features

1

🔐 Cryptographic Delegation Chain  Core Innovation

Every sub-agent runs with its own keypair. delegate() issues a scoped, signed token. invoke() enforces it at runtime. Any tool call outside the declared scope is cryptographically blocked and immutably logged.

2

⏳ Expiring Tokens — Live Demo  Bonus Feature

Delegation tokens carry a TTL. A shopping agent mid-search loses its token live on stage. The agent becomes powerless after expiry — no re-delegation, no inherited authority. Proves the system truly enforces, not just reports.

3

🚨 Scope Violation Detection  Red Team Demo

Shopping agent attempts checkout() — a tool outside its declared plan. ArmorIQ SDK intercepts, records the violation with full chain context (who delegated, when, what scope). The audit trail shows exactly who tried what and was denied.

4

📋 Full Audit Dashboard  Transparency Layer

Streamlit-based UI shows the complete delegation graph in real time: which agent ran which tool, under whose authority, at what time, within what declared plan, and whether it was approved or denied. Fully filterable.

5

🤖 Genuine Multi-Agent Coordination  Real Utility

Coordinator parses user intent, uses capture_plan() to declare intent, then fans work to 3 separate agent processes each with their own MCP server and unique keypair. Real tools doing real work — not simulation.
